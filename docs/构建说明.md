# 词链 WordWeave：Android 构建说明

本项目使用 Android 原生 Java Activity 与本地 WebView 界面。没有第三方运行时依赖；词库、页面和学习逻辑都打包在 APK 中。

## 直接安装

使用交付的 `词链_WordWeave_v1.1.0.apk`，允许文件管理器安装未知来源应用后安装。当前版本为 1.1.0（versionCode 2），最低支持 Android 8.0（API26），面向 Android 15（API35）。本次交付的 APK 沿用前一版本的本地调试证书，可以覆盖前一版本并保留学习数据。

## Android Studio

1. 安装 Android Studio，打开本项目根目录。
2. 使用 JDK17；安装 Android SDK Platform35 与 SDK Build Tools35.0.0。
3. 等待 Gradle 同步完成，然后选择 `app` 并运行，或使用 Build APK。
4. 首次同步需要联网获取 Gradle8.9 和 Android Gradle Plugin8.7.3。项目固定了 Gradle 分发文件的 SHA256 校验值。

Linux/macOS：

```sh
./gradlew assembleDebug
```

Windows：

```bat
gradlew.bat assembleDebug
```

标准 Gradle 产物位于 `app/build/outputs/apk/debug/app-debug.apk`。`local.properties` 是本机 SDK 路径文件，由 Android Studio 自动创建，请勿复制其他电脑的路径。

## 使用官方 SDK 直接构建

如果 Gradle 下载不便，可以通过本项目提供的脚本构建。同样需要已安装的 JDK17、SDK Platform35 和 Build Tools35.0.0，脚本不会替用户下载或接受 SDK 许可证。

```sh
python3 scripts/build_sdk.py --sdk /你的/Android/Sdk
```

Windows 将 `python3` 改为 `python`，SDK 路径可使用引号：

```bat
python scripts\build_sdk.py --sdk "C:\Users\你的用户名\AppData\Local\Android\Sdk"
```

脚本执行 AAPT2 资源编译和链接、Java 编译、D8 转换、zipalign 对齐、apksigner 签名与校验。输出为 `app/build/outputs/apk/debug/wordweave-debug.apk`，并打印 SHA256。

## 调试签名

源码压缩包和 Git 仓库均不附带签名私钥。本次交付的 APK 使用本地保留的旧调试证书；自行构建时，Gradle 优先使用本机的 `signing/debug.keystore`，缺少此文件时使用电脑上的标准调试证书。SDK 脚本在缺少此文件时生成新证书。GitHub Actions 使用运行器生成的临时调试证书，仅上传 APK。

不同证书签名的 APK 不能直接覆盖已安装的应用。需要保留数据时，先在应用中导出备份；使用不同证书的自建版本需要卸载原应用后安装，再导入备份。拥有原签名文件的开发者可在本机配置相同签名以直接更新，签名文件不要提交到 Git。

SDK 脚本生成的调试密钥别名为 `androiddebugkey`，库密码和密钥密码均为标准调试密码 `android`。正式发布时请创建自己的发布签名并妥善保管。

## GitHub Actions

`.github/workflows/android-build.yml` 在推送到 `main` / `master`、提交 Pull Request 或手动运行时构建 APK，先执行语音分段和音色恢复策略检查，再验证 APK 签名并上传构建产物。工作流已配置，尚未在本环境执行 GitHub 托管构建。

本次交付使用官方 SDK 的直接构建流程完成原生编译、签名与对齐验证。具体 APK 哈希、资产一致性和模块测试结果见 `tests/build_validation.json`。此环境未运行安卓真机或模拟器；设备 TTS 提供商、声音下载及系统权限需在安卓设备上体验。
