# 词库格式

本版内置与“大学英语六级核心3500词_关联记忆.xlsx”对应的 3500 个唯一词条，保留 182 个词群顺序。应用从 `app/src/main/assets/vocabulary.json` 加载词库。

运行中的备份导入是学习记录恢复功能，不是导入 Excel 或替换任意词库的功能。修改内置词库后，需要重新构建应用；后续若增加自定义词库导入，应先确定稳定的词条身份和进度迁移规则。

## 根结构

```json
{
  "version": 1,
  "title": "大学英语六级核心3500词·关联记忆",
  "description": "词库范围和编排说明",
  "wordCount": 3500,
  "sources": [
    { "name": "来源名称", "url": "可选来源网址", "scope": "引用范围" }
  ],
  "words": [],
  "groups": []
}
```

`words` 数组顺序即默认学习顺序。词条 `id` 在本版为 1–3500；若修改已有词的 `id`，旧学习记录会失去对应关系。`groups` 数组按词条首次出现的顺序排列。

## 词条

```json
{
  "id": 4,
  "word": "aggressive",
  "meaning": "adj. 好斗的；挑衅的；侵略的；强势的；积极进取的。",
  "ipa": "/əˈgresiv/",
  "pos": "adj.",
  "groupId": "P001",
  "groupLabel": "“雄心”相关",
  "relations": "同根：aggression（攻击行为；侵略）\n近义：assertive（坚定自信的，通常较积极）",
  "forms": "",
  "source": "PDF印刷页2（扫描第10页）"
}
```

示例的释义为节选；实际词库保留整理表中的中文义项，并在不完全相同的情况下附上“补充词典义项”。

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| id | 正整数 | 词条稳定身份，学习进度的关联键 |
| word | 字符串 | 英文词头；3500 个词头不重复 |
| meaning | 字符串 | 中文多义项，可含换行和词性标记 |
| ipa | 字符串 | 音标展示；TTS 发音由设备英语语音负责 |
| pos | 字符串 | 词性展示 |
| groupId | 字符串 | 所属词群标识，必须存在于 groups |
| groupLabel | 字符串 | 词群显示名称 |
| relations | 字符串 | 带关系类型的相关词，词头须在同一词库中存在 |
| forms | 字符串 | 变形或其他写法，可为空 |
| source | 字符串 | 原 PDF 页码或关联拓展说明 |

## 词群

```json
{ "id": "P001", "label": "“雄心”相关", "count": 11 }
```

`count` 是该词群的词条总数。P001–P173 对应原 PDF 词群，S01–S09 是补充主题。词群联想不应解释为严格的同义词集合；具体关系以词条的关系类型为准。

本次生成检查结果：3500 个唯一词条，182 个词群，中文释义、音标和词性无空值；关系文本中的英文词头均可在词库中找到。`PDF` 等标签及 `n.`、`v.` 等词性缩写不作为关系词头。

## 来源和许可

- 用户提供的《英语六级你还在背单词吗.pdf》：用于参考词群结构、排列和关联，不在程序包中附带原 PDF。
- [ECDICT](https://github.com/skywind3000/ECDICT)：用于音标、词性、词典释义和变形，使用 MIT 许可；全文见 `LICENSES/ECDICT_MIT.txt`。
- 人工筛选、常见语境义和关联整理：沿用此前整理的 Excel。

这是按用户学习需求整理的核心词集合，不是官方公布的完整 3500 词考试清单，也不是某本词典的全部义项全集。

## 离线学习例句

`app/src/main/assets/lessons.json`按稳定词条id保存每词一个具体语境：

```json
{
  "version": 1,
  "wordCount": 3500,
  "lessons": {
    "4": {
      "example": "The player became aggressive near the end of the match.",
      "exampleTranslation": "比赛接近结束时，这名球员变得好斗起来。",
      "usage": "aggressive 在本句表示好斗、具有攻击性的。",
      "source": "例句来源与署名",
      "sourceType": "original"
    }
  }
}
```

上例只展示结构。`example`、`exampleTranslation`、`usage`、`source`均为非空字符串。来源类型为`original`（本项目原创）、`tatoeba_pair`（保留原站中英直接对照）、`tatoeba_en_authored_zh`（保留原站英文，新整理中文译文）；Tatoeba项同时记录英文id/作者，原站中文项另记中文id/作者。逐条可追溯索引为`docs/例句来源索引.tsv`，许可与整理过程见[例句来源与校对](例句来源与校对.md)。

例句展示具体用法，不能替代词条完整释义。讲解读取优先使用有效AI学习包缓存，否则读取离线例句；首次讲解确认仅记录`lessonAt`，不计一次成功回忆。

## 可追溯词义校对

`app/src/main/assets/meaning_supplements.json`为根数组：

```json
[
  {
    "id": 127,
    "word": "complimentary",
    "meaningAppend": "六级常用义补充：adj. 免费赠送的；作为礼遇提供的。",
    "referenceUrls": ["https://dictionary.cambridge.org/dictionary/english/complimentary"]
  }
]
```

本版44条校对项包含38条遗漏常用义补充和6条明确误义纠正。`meaningAppend`附加在原完整释义后，保留已有正确义项；真正误义使用`correctedMeaning`给出完整规范释义，并把旧文保存到`originalMeaning`供追溯。必要时`correctedPos`同步规范词性。六处校正为genetically、bankruptcy、supportive、ethical、hardy和fluorescent。

原`vocabulary.json`保持此前资料；运行数据库以校对后的同一释义供完整词卡与AI请求使用；选择题从中计算简短大意，不附加补充词典段落。资产指纹用于幂等更新，只有实际变化词的旧题目/学习包缓存失效，学习状态继续保留。字典来源核查后用中文重新整理，未复制其英文例句。

## 学习备份

v2学习备份保存逐词进度、首次讲解确认时间、复习日志、阅读记录与学习包/三层题缓存；兼容旧v1学习备份。旧词典对应缓存失效时保留进度。备份不带API地址、密钥或模型设置。备份id依赖当前3500词的稳定身份，不应用作任意词库导入格式。
