# 离线例句来源与校对

本版为3500个词各提供一组英文语境例句、中文对照译文和用法说明。例句用于理解其中一种用法；词卡仍显示完整中文多义项。**这些例句不是从用户PDF提取的，也不是六级官方真题例句。**

## 数据组成

最终组成与数量记录在`app/src/main/assets/lessons.json`的`sourceCounts`，并在下方统计。来源分三类：

- `tatoeba_pair`：保留Tatoeba原站英文与直接关联的中文句子。
- `tatoeba_en_authored_zh`：保留Tatoeba英文，本项目逐句整理中文译文与用法。
- `original`：针对现有词义重新编写自然英文、中文译文与具体用法，明确标为本项目原创。

| 类型 | 数量 | 来源与处理 |
| --- | ---: | --- |
| 原站直接关联中英句对 | 1684 | 保留英文、中文及双方作者和句子id |
| 原站英文＋本项目中文 | 718 | 保留英文作者与id，注明新增译文和用法 |
| 本项目原创 | 1098 | 重新编写英文、译文和用法，独立标记来源 |
| 合计 | 3500 | 每词一组，稳定id对应完整词条 |

项目新增例句、译文和用法由AI辅助编写并逐句整理校对。Tatoeba句子来自社区贡献，不代表所有句子均由英语或中文教师审核。保留原站译文可能含繁体字，未把繁体原文默默标成全新的简体译文。

## 筛选和复核

从Tatoeba官方英文、中文详细导出及直接翻译关联中检索词头和词库明确列出的变形，优先选较短、含清晰语境的句子。直接关联用于避免把间接翻译的含义漂移误当作精确中英对照。英文原站来源不足的词，优先保留可用英文后整理译文，其余编写原创例句。

逐句复核目标词、词性、现有义项和中文译文；专名误撞、仅有派生关系而非目标词、明显错译、晦涩或不适合首次理解的例句改为原创。复核中的典型修订包括Jean人名误撞jean牛仔布、lining up动词误作lining衬里、heater枪支俚语与当前义项不符、repertoire整句误译，以及不合语法的maintain句子。改写后去掉旧句id和作者，避免将原创句错误署名给Tatoeba贡献者。

结构检查覆盖3500个稳定id、目标词或有效变形出现、非空译文/用法/来源，以及逐条来源元数据。该检查能发现遗漏和格式问题，不能单独证明所有语言内容永远无误；完整词义和当前语境应结合阅读。

## 逐条署名和许可

`lessons.json`中的`source`包含每条的署名说明。保留Tatoeba英文时有原句id、作者用户名和原站链接；保留其中文翻译时另有中文id、作者及链接。用户名缺失时标为未署名，并保留Tatoeba贡献者整体署名。完整机器可读索引为[例句来源索引.tsv](例句来源索引.tsv)。

Tatoeba文本采用Creative Commons Attribution 2.0 France（CC BY 2.0 FR）。使用和再发布Tatoeba句子、保留翻译或改编译文时，应保留贡献者署名、原句链接及许可链接，注明翻译或其他修改。本项目已经在逐条元数据中区分原站句对与新整理译文；原创例句使用独立来源标记。

完整许可文本随源码放在`LICENSES/TATOEBA_CC_BY_2.0_FR.txt`，APK内为`assets/licenses/TATOEBA_CC_BY_2.0_FR.txt`。出处说明也随APK内置。词典数据单独使用ECDICT MIT许可，不能将所有资料来源混作同一许可。

## 词义校对与AI缓存

例句复核同时发现少量已有资料的常用义遗漏及明确误义。`meaning_supplements.json`保存44条已查证校对项及逐词字典链接：38条追加常用义，6条校正明显错误。原资料留作追溯，运行界面的完整词义、题目正确项和AI输入使用同一校对版本。资料核查参照Cambridge Dictionary、Oxford Learner's Dictionaries、Merriam-Webster和Collins原站，中文释义重新整理，不复制这些词典的英文例句。

AI学习包属于运行时生成内容，成功后缓存在本机；界面明确标为AI材料，不把它伪装成Tatoeba或PDF原句。词义版本变化会使相关旧缓存失效，学习进度保留。
