# 发音与模型使用说明

v1.2.0可以使用手机系统TTS，也可以由词链下载模型并在本机朗读。单词、英文例句和阅读正文使用设置中选定的同一来源。语音合成不使用阅读AI接口，下载语音模型也不需要API Key。

安装需Android 8.0及以上的ARM手机：GitHub有ARM64包（大多数现代手机）和ARMv7包（旧32位手机），本次交付的通用包同时包含两种ARM架构。各包的模型目录与发音功能相同，请按设备架构选择；不支持x86手机或模拟器。

## 用本机模型朗读

1. 打开“设置”，把“朗读来源”选为“词链本机模型 · 应用内管理”。
2. 展开“下载与管理离线模型”，选一个模型并点“下载模型”。首次可先试较小的Kitten。
3. 等待“正在下载 → 正在校验 → 正在安装 → 已就绪 · 可离线”。下载到100%后仍需校验和解压，请等到“已就绪”。
4. 点击该卡的“使用此模型”，或在上方选择“本机模型”和“模型音色”，调整语速，点“保存并试听当前来源”。
5. 回到词卡点击发音，或打开一篇阅读点击“朗读”。安装成功后，可关闭网络确认离线播放。

只需下载所选模型一次，同一模型内换音色不需要再次下载。切换模型、音色或语速会使用新配置重新合成；首次加载和合成耗时取决于手机处理器和模型。模型还未安装好时不会自动换成另一个来源，应等待完成或自行选择系统TTS。

## 阅读播放器

打开已生成或已保存的阅读，正文下有播放进度和控制按钮：

| 操作 | 行为 |
| --- | --- |
| 朗读 | 从篇首开始，播放英文正文 |
| 暂停 | 暂停当前篇；按钮变为“继续” |
| 继续 | 本机模型从暂停的音频位置继续；系统TTS从当前尚未完成的句子开头重读 |
| 停止 | 结束本次播放，再次“朗读”从篇首开始 |

播放器显示当前文本分段与字符进度。模型在后台逐段合成；进度不是音频时长，也不是逐词高亮字幕。正文按句子和长度分段，较长句子可能分为多段。只朗读英文正文，不朗读界面说明或你正在提交的中文译文。切换到另一篇阅读会停止旧篇。

本机暂停位置属于当前播放过程，不是可跨重启恢复的音频书签。系统TTS没有统一的精确音频暂停接口，因此采用按句暂停，继续时可能重复听到一部分内容。

## 下载管理与常见问题

- **取消**：下载、校验和安装中可点“取消”，清理未完成任务；需要时点“重新下载”。
- **删除**：已就绪卡可点“删除”，确认后移除该模型。学习记录保留；如果正在使用它，需要重新下载或选择另一来源。
- **等待网络或下载失败**：检查手机网络和系统下载服务，按显示原因处理后重新下载。系统下载会受网络和设备策略影响。
- **校验或包内容失败**：不会标为就绪；重新下载完整包，不能跳过校验直接使用。
- **看似下载完成但不能发音**：检查是否已到“已就绪 · 可离线”，是否选中了该模型和音色，并点“保存并试听当前来源”。
- **没有声音**：检查媒体音量与当前输出设备。也可切换系统TTS试听，区分设备输出问题与模型问题。

## 用系统TTS朗读

把“朗读来源”切为“系统TTS · 已安装的语音引擎”，选择引擎、英美口音和英语声音，然后点“保存并试听当前来源”。没有可用英语声音时，点“下载 / 安装声音”，在该引擎提供的界面完成下载，返回后点“刷新声音列表”。可用声音、联网要求和音质由手机或语音引擎供应商决定。安装其离线声音后，系统来源也可断网朗读。
