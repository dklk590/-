# 离线模型目录与安装

程序按需下载离线语音，不将大模型权重嵌入 APK。下载目录只提供四个已验证的官方包，用户不能填写任意下载 URL 或本地路径。实际网络下载由 Android 系统 DownloadManager 处理，校验和解包在独立后台线程执行。

| vits-piper-en_GB-alan-medium | 67,220,121 | 81,199,210 | 1 个英式英语音色 |
| kokoro-int8-multi-lang-v1_0 | 132,303,094 | 189,882,497 | 英语 ID 0–27，共 28 个英美音色 |

上述数字来自实际下载并核验的 tar.bz2 包，不是 APK 大小或运行内存。Kokoro 当前归档包含 54 个总音色；英语序号 0–27 沿用已有映射，软件只列这些已验证的英语音色。官方包中多语种辅助文件和声音表原样保留。

模型固定来自 [sherpa-onnx 官方 tts-models 发布](https://github.com/k2-fsa/sherpa-onnx/releases/tag/tts-models)。SHA-256 基线来自官方 [GitHub Release API](https://api.github.com/repos/k2-fsa/sherpa-onnx/releases/tags/tts-models) 的 `digest` 字段；已下载四包实际计算复核一致。大小或哈希不符即拒绝安装，目录更新需要更新应用，不能静默接收替换内容。

## 生命周期

下载任务 ID 与处理状态存在应用私有偏好中。下载过程中可离开模型页面；下次打开软件，会向系统查询实际下载状态。完成后开始 SHA-256 校验、安全解包和原子安装，只有全部成功才显示“已安装”。若网络中断，系统可能暂停等待恢复；系统判定失败则显示可重试错误。

Activity 销毁时调用 `ModelDownloadManager.close()`：注销其完成通知监听、取消校验/解包线程，但保留系统下载任务和完整压缩包。下一实例重新检查并继续安装，途中不遗留可用状态的半成品。用户点击“取消”则改变任务令牌、取消系统任务并清理压缩包。重复点击下载会返回现有状态，避免同模型重复下载。

删除前，调用方需通过 SpeechManager 安全关闭该模型的正在进行或已缓存推理。模型目录先移出可见路径，再后台删除。取消行为不会删除已经安装好的模型；删除是单独动作。

## 文件与安全边界

下载文件位于应用自己的 external-files `tts_downloads` 目录；安装后的模型在 `getNoBackupFilesDir()/offline_tts/models/<固定模型ID>`。模型权重不会进入学习记录备份。安装临时目录与最终模型处于同一文件系统，文件完整后通过重命名发布；替换失败恢复旧模型，重新启动时也处理遗留备份。

解包保留全部普通文件、目录、原 `LICENSE`/`MODEL_CARD` 等资料，另外写入应用的来源说明与安装清单。拒绝路径穿越、绝对路径、反斜杠/驱动器路径、错误根目录、重复文件、符号链接、硬链接、FIFO/设备等特殊文件；限制条目数量及总展开字节，不应用归档中的执行权限、所有权。原包即使带“官方”标记，也必须先通过固定哈希。

准备下载时保守预留压缩包、展开文件及 32 MiB 余量，避免常见手机共享数据分区仅够下载而不够安装。安装前还会重新检查可用空间。校验失败、缺必需文件、存储不足或取消都不会启用不完整模型。

## 读取接口

```java
ModelCatalog.Entry entry = ModelCatalog.get(modelId); // 未知 ID 直接拒绝
JSONObject publicDescriptor = ModelCatalog.descriptor(modelId);
ModelDownloadManager manager = new ModelDownloadManager(context);
JSONObject catalog = manager.catalog();
JSONObject state = manager.start(modelId); // 快速返回，由系统后台下载
JSONObject current = manager.status(modelId); // 完成时自动排队校验安装
manager.cancel(modelId);
manager.delete(modelId); // 调用前先安全释放该模型
manager.refreshAll();
boolean ready = manager.isReady(modelId);
File directory = manager.installedModelDirectory(modelId);
JSONObject runtimeDescriptor = manager.descriptor(modelId); // 仅 ready 可取
manager.close(); // Activity 销毁；不移除系统下载任务
```

运行描述含绝对 `modelPath`、`tokensPath`、`voicesPath`、`dataDir`、`usLexicon`、`gbLexicon`，模型类型为 `kitten` / `vits` / `kokoro`。声音列表以 `speakers` 与 `voices` 两个同义字段提供，每项为 `{id,sid,label,locale,gender}`，`id`/`sid` 相同。Kokoro 英音使用对应 GB 词典，美音使用 US 词典；具体切换由语音后端处理。

目录状态包括 `not_downloaded`、`downloading`、`verifying`、`installing`、`ready`、`error`、`cancelled`。UI 可以每秒查询目录，无需等待整个下载请求返回。只有原生后端的 ready 判定成功才允许推理；下载前保存选择不等于已经可用。

## 验证范围

`tests/ModelDownloadSafetyTest.java` 通过 76 项目录与合成攻击测试；带四个真实官方包运行时共 80 项，并实际解包验证了所有模型与语音必需文件。结果记录在 `tests/model_download_validation.json`。主机测试只依赖 Android API 编译桩、测试用 org.json 和正式 Commons Compress 及其依赖；这些测试不调用收费 API。

Android DownloadManager 通知、进程重启与网络策略仍需在手机上验证；主机安全测试没有伪称已实测这些系统行为，也没有把模型文件大小当作推理 RAM。
