SQLite检查在容器中运行生产SQL的关键语句，未在Android系统执行完整Java数据库层。TTS检查使用可控的Android接口替身，不能证明每个手机供应商的语音都可用。AI测试使用本地模拟服务，没有你的真实Key或收费服务调用。界面检查使用模拟原生桥及测试数据；交付APK加载真实内置3500词、3500组离线例句与本地学习记录。安装包资源与工程资产逐文件核对。

词库检查覆盖3500个唯一稳定id、182个词群、完整非空中文释义/音标/词性，以及关系词头在库内可解析。离线例句检查覆盖全部3500id、中文译文/用法/来源非空、英文目标词或有效变形出现；开放来源句的id和作者可追溯。44条词义校对包含38条补义和6处明确误义校正，保留原文记录。

首次[GitHub Actions自动构建](https://github.com/dklk590/-/actions/runs/38160324722)已成功完成编译、语音策略检查、APK签名验证与产物上传。该记录是源码发布后的新增验证；交付APK原始SDK构建报告仍保留发布前的状态。

本环境没有真实Android设备或可用的硬件加速模拟器。尚未完成真机安装、实际TTS、提醒、文件选择器与在线AI全流程测试。首次使用可依次确认：

1. 在设置中选择已安装引擎和英语声音，点击保存并试听；如无声音，打开“安装/下载语音数据”，下载后刷新列表。
2. 开启复习提醒并允许通知权限；确认到期词可在应用中查看，省电策略可能让通知延迟。
3. 导出一次学习备份，确认系统文件选择器可保存；需要恢复时再导入。
4. 配置实际API地址、Key和Model，先测试连接，再生成学习包和阅读，提交一次中文翻译。真实服务兼容性与费用以该服务商为准。

本次APK使用与v1.0相同的本地调试证书，可覆盖该旧版。源码和GitHub仓库不含固定签名私钥；其他电脑或CI生成的新调试证书可能不同，不能直接覆盖已有安装。换签名或卸载前先导出学习备份，持续发布请自行管理固定发布签名。
