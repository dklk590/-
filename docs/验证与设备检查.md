SQLite检查在容器中运行生产SQL的关键语句，未在Android系统执行完整Java数据库层。782项语音检查执行生产Java播放/进度规则，不调用Android设备音频服务；系统TTS提供商及声音下载也未在手机测试。界面检查使用模拟原生桥和测试数据，102是桥接请求次数，不是102个独立测试断言。AI测试使用本地模拟服务，没有你的真实Key或收费服务调用。

Linux上已使用真实原生CPU JNI，分别合成Kitten、Piper英美和Kokoro英美样例。Piper输出22050Hz、Kokoro输出24000Hz；相应WAV另经独立检查确认单声道、帧数匹配且非静音，详情见`tests/native_model_validation.json`。该结果未验证Android JNI加载、AudioTrack播放、手机性能或全部音色。模型本体不内置于APK，应用在下载包通过校验并安装后才标为可用；下载安全检查不能代替Android DownloadManager在真实网络和设备上的端到端测试。

源码内固定的`app/native/*.so.gz`和还原后的JNI均进行SHA256核对；Gradle用Java自动还原，SDK脚本调用Python还原，无需联网下载运行库。源码ZIP不包含固定签名私钥。通用APK内JNI未压缩并作条目对齐；分架构小包内JNI压缩、安装时解压。打包检查不等同于16KB页大小设备的实际运行结果。

词库检查覆盖3500个唯一稳定id、182个词群、完整非空中文释义/音标/词性，以及关系词头在库内可解析。离线例句检查覆盖全部3500id、中文译文/用法/来源非空、英文目标词或有效变形出现；开放来源句的id和作者可追溯。44条词义校对包含38条补义和6处明确误义校正，保留原文记录。

[v1.1 GitHub Actions历史构建](https://github.com/dklk590/-/actions/runs/38160324722)已成功。v1.2.0增加了原生运行库与JAR依赖，最新托管构建结果需核对[Actions页面](https://github.com/dklk590/-/actions)的对应版本和提交，不能把旧版成功记录当作新版结果。

本环境没有真实Android设备或可用的硬件加速模拟器。尚未完成真机安装、本机模型下载与播放、系统TTS、提醒、文件选择器与在线AI全流程测试；16KB页大小设备也未实测。首次使用可依次确认：

1. 在设置选择本机模型，下载后等待“已就绪 · 可离线”，保存模型/音色并试听。断网后分别播放单词和例句，确认音量与输出正常。
2. 打开一篇阅读，确认朗读、暂停、继续、停止和切换篇目。本机来源从暂停音频位置继续；系统来源会重读当前未完成句子。
3. 如选择系统TTS，选已安装引擎和英语声音并试听；缺声音时用“下载 / 安装声音”，完成后刷新列表。
4. 开启复习提醒并允许通知权限；确认到期词可在应用中查看，省电策略可能让通知延迟。
5. 导出一次学习备份，确认系统文件选择器可保存；需要恢复时再导入。模型大文件不在学习备份中。
6. 配置实际API地址、Key和Model，先测试连接，再生成学习包和阅读，提交一次中文翻译。真实服务兼容性与费用以该服务商为准。

本次APK使用与v1.0相同的本地调试证书，可覆盖该旧版。源码和GitHub仓库不含固定签名私钥；其他电脑或CI生成的新调试证书可能不同，不能直接覆盖已有安装。换签名或卸载前先导出学习备份，持续发布请自行管理固定发布签名。
