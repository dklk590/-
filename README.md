# WordWeave · 词链记忆

Android 六级单词学习程序，内置此前整理的 **3500 个核心词、182 个词群和3500组离线例句**。通过同根、近义、反义、易混和词群关系建立联系，按每个词的学习记录逐步进入认识、拼写与阅读。

## 安装和第一次使用

1. 在 Android 8.0 或以上手机安装随包`词链_WordWeave_v1.1.0.apk`。系统询问时，允许用于打开此安装包的文件管理器或浏览器安装应用。
2. 打开设置，调整每日新词数、单次练习数和发音。默认每天15个新词、每次12张卡；新词数设为0时只复习。
3. 点击“开始今日学习 · 按每词进度”。先完成到期词，再沿词群顺序学新词；队列交错不同词群的复习。
4. 新词先看完整中文义项、词性、音标、自然例句、译文和相关词，播放发音。理解后点“已经理解 · 开始四项选择”，再尝试独立回忆。
5. 认识与拼写可以离线使用。配置自己的 AI 服务后，可主动生成学习讲解及题目、阅读材料与译文评价。

查看讲解、发音或点击“已经理解”只表示接触了这个词，不会直接算作成功回忆。

## 每词三个阶段

| 阶段 | 练习 | 推进 |
| --- | --- | --- |
| 认识 | 看英文后先回忆，完成四项词义选择；逐词从明显区分到同类、近义辨析 | 3次独立成功，计入晋级的练习间隔至少20小时 |
| 拼写 | 根据完整中文义项和词性输入英文，核对后记录难度 | 2次独立成功，计入晋级的练习间隔至少20小时 |
| 阅读 | AI把学过的词放入连贯英文；提交中文翻译，再看评价和纠正 | 自己评价各目标词的掌握情况，继续间隔复习 |

阶段按词保存：某个词进入拼写时，其他词仍可继续认识。选择题始终四项；题目层级依据该词的练习记录变化，不随整个词库统一升级。词条中的完整义项始终保留，例句只示范一个具体语境。

“忘记”安排10分钟后重练，并退回一个阶段；“提示后想起”安排30分钟后复习，不计晋级。初次正常成功后约20分钟复习，后续基础间隔为1、3、7、14、30天，再根据难度延长。AI评分不会直接改变阶段或间隔；提前阅读也不会推迟尚未完成的认识、拼写复习。具体规则与研究依据见[记忆与复习设计](docs/记忆与复习设计.md)。记忆趋势为复习紧迫性提示，未测量个人遗忘概率。

## AI阅读和学习缓存

阅读页优先建议进入阅读阶段的到期词，也允许选择3–8个此前学过的词提前阅读。可以选短篇（80–140词）或长篇（260–420词），以及轻松、标准、挑战难度；额外目标生词可设0–8个。新增词单独显示，点击查看本段语境义并发音，不会自动算学过或推进阶段。额外生词数量只控制指定目标，无法保证正文其他非目标词都已认识。

学习页的“用 AI 准备讲解与选项”会为当前词和随后若干词批量生成自然例句、用法与三层四项选择题，并缓存到本机。已缓存材料重复学习直接读取；没有后台自动收费开关。AI可能生成有争议的辨析题，应结合完整词义核对。

## 发音与提醒

设置可选择已安装的TTS引擎、英美口音、具体英语声音和语速，并保存后试听。“安装/下载语音数据”打开所选引擎提供的下载入口，完成后点刷新重新选择声音。英语声音包由手机系统或引擎供应商提供，应用不自带所有语音包；可用声音、音质和联网要求取决于该引擎。安装可用的离线英语声音后，可离线朗读词语、例句和阅读。

提醒需在应用中开启，并允许Android通知权限。默认每日20:00检查到期词，可修改时间。使用非精确系统闹钟，省电策略可能让提醒延后；提醒只通知回来学习，不调用AI。应用内到期列表可随时查看。

## 配置 API

设置中填写服务商的 **API地址、API Key、Model和超时**。程序使用兼容 OpenAI Chat Completions 的非流式协议：`Authorization: Bearer <Key>`，`POST /chat/completions`，请求包含`model`和`messages`。接口根地址、`/v1`或完整`/chat/completions`均可填写，具体拼接见[API说明](docs/API说明.md)。其他协议需要适配客户端。

正常使用HTTPS。本地HTTP开关仅允许`localhost`、`127.0.0.1`、模拟器宿主机测试地址`10.0.2.2`，不接受普通局域网或公开互联网HTTP地址。

只有点击连接测试、准备AI学习包、生成阅读或提交翻译评价时才发出API请求。连接测试也调用一次接口；批量准备会发送本次目标词及完整义项；阅读生成还发送指定额外生词；评价发送原文、目标词和你提交的中文译文。学习记录不会自动上传。服务商可能计费，失败后不自动重试。

密钥由Android Keystore加密保存。保存时Key留空保留旧Key，明确清除才删除。三个任务提示词位于`app/src/main/assets/prompts/`，修改后重新构建即可使用。未使用你的真实地址、Key和模型进行在线调用测试，配置后请先做连接测试、生成材料并提交一次翻译。

## 备份与词库资料

学习进度、讲解确认时间、复习日志、学习包/题目缓存和阅读记录保存在本机；JSON备份通过Android系统文件选择器导出、导入。导入替换当前学习记录，请先导出当前备份。备份不包含API设置或Key，换机后需重新配置。当前没有Excel导入或任意词库替换界面，学习备份导入不是词库导入。

## 源码与构建

工程使用Java原生Android服务和本地网页界面，SQLite保存学习状态，原生侧负责TTS、提醒、备份和AI请求。学习界面、词库和离线例句均随APK打包。

使用JDK17、Android SDK35及Build Tools35.0.0。在Android Studio打开工程，或配置`ANDROID_HOME`后执行：

```bash
./gradlew :app:assembleDebug
```

Windows：`.\gradlew.bat :app:assembleDebug`。输出为`app/build/outputs/apk/debug/app-debug.apk`；首次构建需下载依赖。GitHub Actions提供自动构建并上传APK的工作流，详见[构建说明](docs/构建说明.md)。

交付APK为调试签名版本。CI没有本地私钥时使用新调试签名，证书可能与当前安装版不同，无法直接覆盖安装；需要持续升级时请自行管理固定私钥和正式签名，私钥不要提交到仓库。覆盖安装前建议导出学习备份。

验证结果见[验证与设备检查](docs/验证与设备检查.md)。本次未在真实Android设备上完成系统语音、通知和安装全流程测试，需在自己的手机确认这些设备功能。
