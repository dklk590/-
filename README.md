# WordWeave · 词链记忆

Android 六级单词学习程序，内置此前整理的 **3500 个核心词、182 个词群和3500组离线例句**。通过同根、近义、反义、易混和词群关系建立联系，按每个词的学习记录逐步进入认识、拼写与阅读。

## v1.3.0 学习调整

- 词义选择只检查大意，三个练习层级均避免用近义解释互相设为错误选项。选项统一为简短词义；完整释义在学习卡和答题后展示。
- 学习卡按词性展示同根词，默写时为已学过的同根词分别提供输入框，逐项核对。只读取明确标注的同根关系，不把同一词群或相似前缀当作同根。
- 每个默写词都可单独听读音、查看音标；输入内容保留。听音、纠错后的练习按提示回忆处理。
- 选择题作答前隐藏 AI 讲解入口，清理界面中的编题、缓存与阶段实现说明。升级会替换旧题缓存，保留学习记录。

## 安装和第一次使用

1. 在Android 8.0或以上的ARM手机，安装对应架构的GitHub APK，或随本次交付的双架构通用APK。系统询问时，允许用于打开此安装包的文件管理器或浏览器安装应用。
2. 打开设置，调整每日新词数、单次练习数和“朗读来源”。默认每天15个新词、每次12张卡；新词数设为0时只复习。系统TTS可直接使用已安装的英语声音；本机模型需要先下载并安装。
3. 点击“开始今日学习 · 按每词进度”。先完成到期词，再沿词群顺序学新词；队列交错不同词群的复习。
4. 新词先看完整中文义项、词性、音标、自然例句、译文和相关词，播放发音。理解后点“已经理解 · 开始四项选择”，再尝试独立回忆。
5. 认识与拼写可以离线使用。配置自己的 AI 服务后，可主动生成学习讲解及题目、阅读材料与译文评价。

查看讲解、发音或点击“已经理解”只表示接触了这个词，不会直接算作成功回忆。

## 每词三个阶段

| 阶段 | 练习 | 推进 |
| --- | --- | --- |
| 认识 | 看英文后先回忆，完成四项大意选择；干扰项保持含义明确不同 | 3次独立成功，计入晋级的练习间隔至少20小时 |
| 拼写 | 根据中文大意与词性输入英文，并联写已学的同根词，逐项核对 | 2次独立成功，计入晋级的练习间隔至少20小时 |
| 阅读 | AI把学过的词放入连贯英文；提交中文翻译，再看评价和纠正 | 自己评价各目标词的掌握情况，继续间隔复习 |

阶段按词保存：某个词进入拼写时，其他词仍可继续认识。选择题始终四项；题目层级依据该词的练习记录变化，不随整个词库统一升级。词库中的完整义项始终保留，选择题选项仅显示简短大意；完整释义在学习及作答后查看，例句只示范一个具体语境。

“忘记”安排10分钟后重练，并退回一个阶段；“提示后想起”安排30分钟后复习，不计晋级。初次正常成功后约20分钟复习，后续基础间隔为1、3、7、14、30天，再根据难度延长。AI评分不会直接改变阶段或间隔；提前阅读也不会推迟尚未完成的认识、拼写复习。具体规则与研究依据见[记忆与复习设计](docs/记忆与复习设计.md)。记忆趋势为复习紧迫性提示，未测量个人遗忘概率。

## AI阅读和学习缓存

阅读页优先建议进入阅读阶段的到期词，也允许选择3–8个此前学过的词提前阅读。可以选短篇（80–140词）或长篇（260–420词），以及轻松、标准、挑战难度；额外目标生词可设0–8个。新增词单独显示，点击查看本段语境义并发音，不会自动算学过或推进阶段。额外生词数量只控制指定目标，无法保证正文其他非目标词都已认识。

新词学习卡的“补充 AI 例句与讲解”会为当前词和随后若干词批量生成自然例句、用法与三层四项大意选择题，并缓存到本机。已缓存材料重复学习直接读取；没有后台自动收费开关。题目不考近义解释的细微差别；AI输出仍需核对。

## 发音与阅读朗读

设置中选择“朗读来源”，单词、英文例句和阅读正文均使用同一来源：

- **系统TTS**：选择已安装的语音引擎、英美口音和英语声音。“下载 / 安装声音”打开引擎供应商入口；下载后刷新声音列表。是否离线、可用音色与音质取决于该引擎。
- **词链本机模型**：展开“下载与管理离线模型”，点击下载，等待“下载 → 校验 → 安装”完成。再选择模型和音色，点“保存并试听当前来源”。首次下载需要联网，完成后在本机合成，无需AI地址、Key或再次联网。

| 本机模型 | 下载包 | 可选英语音色 |
| --- | ---: | --- |
| Kitten Nano 0.8 INT8 | 31.2 MB | 8个；原站未逐音色标注英美口音 |
| Piper Lessac | 67.2 MB | 1个美式英语音色 |
| Piper Alan | 67.2 MB | 1个英式英语音色 |
| Kokoro v1.0 INT8 | 132.3 MB | 28个：20个美式、8个英式 |

表中MB按1,000,000字节计算；安装还需解压和临时空间，设置页会显示存储信息。可取消未完成任务、删除已安装模型，再按需重新下载，学习记录保留。下载使用内置官方HTTPS地址和固定SHA256校验；失败时显示原因，不会把未校验文件当作可用模型。模型许可及原始来源在模型卡中显示，下载包保留原许可。

阅读正文下有“朗读、暂停、继续、停止”，并显示段落、字符进度。本机模型保留已合成音频的暂停位置；系统TTS继续时从尚未读完的句子开头重读。进度表示文本播放位置，并非逐词字幕或精确音频时长。切换阅读篇目会停止旧篇朗读。具体操作见[发音与模型使用说明](docs/发音与模型使用说明.md)。

## 提醒

提醒需在应用中开启，并允许Android通知权限。默认每日20:00检查到期词，可修改时间。使用非精确系统闹钟，省电策略可能让提醒延后；提醒只通知回来学习，不调用AI。应用内到期列表可随时查看。

## 配置 API

设置中填写服务商的 **API地址、API Key、Model和超时**。程序使用兼容 OpenAI Chat Completions 的非流式协议：`Authorization: Bearer <Key>`，`POST /chat/completions`，请求包含`model`和`messages`。接口根地址、`/v1`或完整`/chat/completions`均可填写，具体拼接见[API说明](docs/API说明.md)。其他协议需要适配客户端。

正常使用HTTPS。本地HTTP开关仅允许`localhost`、`127.0.0.1`、模拟器宿主机测试地址`10.0.2.2`，不接受普通局域网或公开互联网HTTP地址。

只有点击连接测试、准备AI学习包、生成阅读或提交翻译评价时才发出API请求。连接测试也调用一次接口；批量准备会发送本次目标词及完整义项；阅读生成还发送指定额外生词；评价发送原文、目标词和你提交的中文译文。学习记录不会自动上传。服务商可能计费，失败后不自动重试。

密钥由Android Keystore加密保存。保存时Key留空保留旧Key，明确清除才删除。三个任务提示词位于`app/src/main/assets/prompts/`，修改后重新构建即可使用。未使用你的真实地址、Key和模型进行在线调用测试，配置后请先做连接测试、生成材料并提交一次翻译。

## 备份与词库资料

学习进度、讲解确认时间、复习日志、学习包/题目缓存和阅读记录保存在本机；JSON备份通过Android系统文件选择器导出、导入。导入替换当前学习记录，请先导出当前备份。备份不包含API设置、Key或离线语音模型文件；换机后重新配置服务和下载模型。当前没有Excel导入或任意词库替换界面，学习备份导入不是词库导入。

词群参考用户PDF；词义、音标和变形参考[ECDICT](https://github.com/skywind3000/ECDICT)，保留MIT许可。离线例句来自[Tatoeba开放句库](https://tatoeba.org/en/downloads)与本项目原创、逐句整理译文，逐条例句记录来源，Tatoeba采用[CC BY 2.0 FR](https://creativecommons.org/licenses/by/2.0/fr/)。例句并非来自原PDF。完整出处及许可见[例句来源与校对](docs/例句来源与校对.md)和`LICENSES/`；数据结构见[词库格式](docs/词库格式.md)。

## 源码与构建

工程使用Java原生Android服务和本地网页界面，SQLite保存学习状态，原生侧负责TTS、提醒、备份和AI请求。本机语音通过Sherpa-ONNX原生CPU运行库合成；工程也使用解压与Kotlin等依赖。学习界面、词库、离线例句和运行库随APK打包，语音模型按需下载。

源码和源码ZIP包含7个固定JAR及`app/native/*.so.gz`压缩原生库。Gradle构建前自动校验压缩文件与还原后的SHA256，并还原到`app/src/main/jniLibs/`；这一步使用Java，不需另装Python，也不联网获取运行库。直接SDK构建脚本使用Python完成同样的校验还原。

应用软件采用GPL-3.0-or-later；第三方代码和模型各自保留其许可。ECDICT词典的MIT和Tatoeba例句的CC BY 2.0 FR保持独立，详见`LICENSES/`及APK内出处说明。

使用JDK17、Android SDK35及Build Tools35.0.0。在Android Studio打开工程，或配置`ANDROID_HOME`后执行：

```bash
./gradlew :app:assembleDebug
```

Windows：`.\gradlew.bat :app:assembleDebug`。输出为`app/build/outputs/apk/debug/app-debug.apk`；首次构建需下载依赖。GitHub Actions提供自动构建并上传APK的工作流，详见[构建说明](docs/构建说明.md)。

交付APK为调试签名版本。CI没有本地私钥时使用新调试签名，证书可能与当前安装版不同，无法直接覆盖安装；需要持续升级时请自行管理固定私钥和正式签名，私钥不要提交到仓库。覆盖安装前建议导出学习备份。

验证结果见[验证与设备检查](docs/验证与设备检查.md)。782项纯Java语音检查与界面模拟回归已覆盖新功能，Linux上已实际合成Kitten、Piper英美及Kokoro英美语音；本次没有Android真机测试，仍需在自己的手机确认下载、音频输出、暂停继续、系统语音和通知。
